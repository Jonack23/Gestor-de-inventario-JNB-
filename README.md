# Tienda JNB

Programa en C++ de modo texto para gestionar el inventario y las ventas de una tienda. Proyecto de Fundamentos de Programación (UCA).

## Qué incluye esta versión

- Inicio de sesión (máximo 3 intentos)
- Roles: jefe y empleado
- Menú principal según el rol
- Ayuda e integrantes

Las funciones de inventario, ventas y reportes son marcadores temporales que solo imprimen un mensaje.

## Cómo ejecutar

```
g++ main.cpp -o tienda
./tienda
```
