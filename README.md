# Gestor de Inventario "Tienda JNB"

Sistema de consola en C++ para automatizar las operaciones diarias de una pequeña tienda. Reemplaza el control manual en papel por una herramienta digital que evita pérdidas de mercadería, controla el acceso del personal y facilita el cálculo de ganancias.

Proyecto grupal de Fundamentos de Programación, UCA.

## Funciones

- Login de administrador y empleado
- Registro, listado y búsqueda de productos
- Alerta de stock crítico (menos de 5 unidades)
- Ventas con actualización automática del inventario

## Cómo ejecutarlo

```bash
g++ main.cpp -o tienda
./tienda
```
