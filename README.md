Proyecto: Gestor de inventario "Tienda JNB"

Diseñado específicamente para automatizar las operaciones diarias de una pequeña tienda ("tiendita JNB"). Su objetivo principal es reemplazar el control manual en papel por una herramienta digital que evite pérdidas de mercancía, controle el acceso del personal y facilite el cálculo de ganancias.
